## About

**Sabielle** is my personal portfolio-a space to introduce myself, showcase the things I've built, and share a little bit of my journey as a developer.

I wanted it to feel personal rather than like another generic developer portfolio. So, naturally, it comes with a little sakura-inspired charm.

## ✿ Features

- Minimal, elegant interface with a dark aesthetic.
- Sakura-inspired theme with soft pink details.
- Interactive hover effects and visual transitions.
- Falling cherry blossom petals.
- Personal introduction, projects, skills and contact information.
- Responsive layout for different screen sizes.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
